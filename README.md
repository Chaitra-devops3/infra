# ZenPharma Infrastructure - Feature Branch

This branch is created to practice Git branching and feature development.

## Purpose

This feature branch is used to make and test infrastructure-related changes
without directly modifying the main branch.

## Infrastructure

The ZenPharma infrastructure is managed using Terraform.

The infrastructure includes:

- VPC
- EKS cluster
- ECR repositories
- RDS database
- IAM roles and GitHub OIDC
- AWS Secrets Manager

## Branch

Feature branch: `feature`

Changes made in this branch can be reviewed and merged into `main`
after testing is completed.
